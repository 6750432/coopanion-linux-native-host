外挂：配色-深海青
================================================================
作用
    给鲸鱼娘加一套自己的配色（原来的 DeepSeek 蓝 → 深海青），并把她切过去。
    现在一共有 9 套：deepseek(原版) / harness(纯黑) / chatgpt(银白) / claude(赤陶) /
    gemini(四色) / qwen(紫) / kimi(黑蓝) / minimax(玫红橙) / **deepsea(深海青)**。

怎么染的（染色.py）
    母版几何完全共用，每套配色只是一组同形状的贴图 —— 所以不需要画新图：
      1. 把每张贴图转到 HSV；
      2. 掩膜 = 「色相落在蓝色段(140~200)」且「饱和度 ≥ 40」——白、灰、皮肤都排除在外；
      3. 只在掩膜内把色相从 140~200 线性重映射到 100~160（整体约 -56°），饱和度 ×1.12；
      4. alpha 原样保留。
    实测：头发由蓝变青、裙子变绿、围裙上的鲸鱼变绿，**皮肤一点没动**（face.png 前后逐像素一致）。

装了什么
    1. app/.../web/whale/schemes/deepsea/{tex,feat}/*.png   （45 张，染色生成）
    2. model.json 的 schemes 数组里加一条 deepsea（先备份 model.json.原版备份）
    3. config.json 的 worlds.desktop-pet.skin.scheme = deepsea（先备份 config.json.原版备份）

坑
    · 染色要用带 PIL 的解释器（脚本默认用 ~/dsh-pet-opt/.venv/bin/python）。
    · 装完必须重启才生效。
    · 卸的时候贴图不删，挪到本目录的「生成过的贴图/」，想再装回来直接跑装.sh。

想换别的颜色
    改 染色.py 顶部两个常量就行：
      目标色相段 = (100, 160)   # 调成 (0, 60) 是暖粉红，(60, 120) 是青绿，(160, 220) 是紫
      饱和度增益 = 1.12’        # 越大越艳
    改完把 scheme id 换一个（比如 deepsea2）、清掉 model.json.原版备份，再跑装.sh。
