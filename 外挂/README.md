# 外挂（可装可卸的扩展）

主干只负责「让她跑起来」，**其它一切都不许污染主干**。所有额外功能、人设、配色、联动都放这里，
每个外挂是一个独立目录，自带 `装.sh` / `卸.sh`，装上能卸干净。

## 约定（简单版）

1. 外挂就摆在这两张文件夹里，**不用装也不用卸**：
   - `外挂/<名字>/` 里放 `装.sh`（应用）`卸.sh`（还原）`说明.txt`（一句话说明）；
2. 想不想用，只看 **`外挂/启用.json`** 里那个 true/false；
3. 改完点 **外挂管理器**（桌面图标，或者 `bash 外挂/管理器.sh`）里的「应用」/「应用并重启桌宠」；
4. 每次 `启动.sh` 也会自动照 `启用.json` 同步一次 —— 所以**开着就一直开，关了就一直是关的**；
5. 想加一个新外挂：往 `外挂/` 丢一个目录（带 `装.sh`/`卸.sh`/`说明.txt`），管理器里自动出现。

规矩：
- **只读主干**：外挂不许改 `外壳.py` / `启动.sh` / `开.sh` / `停.sh` / `兜异常.cjs`。
  （`启动.sh` 里只有一行「调用 应用.sh」，想彻底不要外挂删掉那一行即可。）
- **改什么先备份**：覆盖 App 里原有文件的先进 `*.原版备份`，卸的时候从备份还原。
- **别偷偷起进程**：需要进程的（本地引擎、代理）在说明里写清楚，并配一个停法。

## 常用命令

```bash
bash ~/coop-linux/外挂/管理器.sh          # 图形管理器（也能双击桌面图标）
bash ~/coop-linux/外挂/应用.sh            # 只同步，不重启
bash ~/coop-linux/外挂/应用.sh --重启     # 同步 + 重启桌宠
```
