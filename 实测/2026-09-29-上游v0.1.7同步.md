### figure.js 的 55 行改了什么（逐条对照）

1. **眉毛**：新增变形器 `brows`（warp，挂在 `headFeat` 下），并**把同一张贴图在刘海上再画一次**
   （`brows_through`，`z=13.2`、`alpha=.4`）—— 所以眉毛能"透"过刘海看见。
2. **眼皮褶线**：新增变形器 `creases`（warp，同样挂在 `headFeat` 下）。
3. **新增 `BROW` 表**：每个表情一组 `[整体抬起, 内端抬起]`，**内端为负就是皱眉**。
   分隔点是 `U(765)`：近眉在它左边、远眉在右边，用 `k²` 把抬起效果集中到内端。
4. **新增 `lidDrop` / `lidOpen`**：眼皮褶线跟着上眼皮一起下移；眼睛不是睁眼型（爱心眼、眯眼）时整条淡出。
5. **坐姿层**：`waist_bow_front` / `waist_bow_sit_front` 的透明度跟裙摆同一逻辑（`1-sitIn` / `sitIn`）。

## 3. 实测：v0.1.7 让渲染贵了多少

同一台机器、同一个脚本、只换素材版本（offscreen，8 次 `thread_time` 均值）：

| 格步 | 网格格数 | 现状 ms/帧 | 变化 | 「快版 A」ms/帧 | A 加速 | A 的像素差异 |
|---|---|---|---|---|---|---|
| 1 | 547 → **764** | 35.85 → **46.29** | **+29%** | 18.12 → **25.15** | **1.84×** | 9.51% / 严重 **0** 个 |
| 2 | 148 → **204** | 12.52 → **16.31** | **+30%** | 7.62 → **10.79** | **1.51×** | 5.60% / 严重 **1** 个 |
| 3 | 81 → **122** | 8.47 → **12.62** | **+49%** | 5.73 → **8.27** | **1.52×** | 3.76% / 严重 **2** 个 |

**结论两条：**

1. **上游这次重画让 CPU 渲染成本涨了约 30~50%** —— 部件 16→25、网格格数涨了 40~50%，
   这是"画得更多"，不是"画得更慢"。想要回到原来的开销，把 `COOP_GRID` 调大即可
   （例如 v0.1.7 用 `COOP_GRID=4`）。
2. **「快版 A」在 v0.1.7 上依然成立**：1.51~1.84× 加速，且像素等价依然成立
   （「肉眼可见级」差异只有 0~2 个像素，全是边缘抗锯齿）。
   **换句话说：如果采纳快版 A，v0.1.7 的渲染开销能压到比 v0.1.6 还低。**

> 注：这里的「严重」= 单通道差 ≥65/255 的像素数。9.51% 的"不同"是亚像素抗锯齿，
> 放大到 8 倍也看不出来 —— 这也是为什么不能只看"有多少像素不同"这一个数字。

## 4. 顺手修掉的一个真缺陷：屏幕尺寸读不到时她不显示

复现：在某些 X 环境下 `QGuiApplication.primaryScreen().availableGeometry()` 返回 **0×0**
（本次在受限会话里 100% 复现；**同样的环境下，一个 5 行的原生 Qt 探针也返回 0×0**，
所以这是环境问题，不是本项目引入的）。

**但我们的代码原来没有兜底**，后果很严重：

- 窗口 `move()` 用的是 `方.center().x()` / `方.bottom()` → 0×0 时算出来是负数 → 被 X 夹到 **(0,0)**；
- 身体的漫游边界 `边界=lambda: (0, 0, -2, 缩放)` 退化成空 → **她一个像素都画不出来**，
  而日志里"重绘 47 次、每次 25 ms"一切正常 —— 典型的**静默失败**。

修法（`原生/原生身体.py` 的 `取屏幕()`）：`availableGeometry()` → `geometry()` →
环境变量 `COOP_SCREEN=宽x高` → `1920×1080`，四级兜底，每级退化都写日志。

修完实测：窗口从 (0,0) 正确落到屏幕底部，画面正常。

## 5. 复现方式

```bash
# 1) 取 v0.1.7 素材（或直接用官方 AppImage 解包后的那一份）
#    web/ 目录里要有 whale/ 与 rig/
export COOP_ASSETS=/path/to/v0.1.7/web

# 2) 离线看渲染（不开窗）
QT_QPA_PLATFORM=offscreen python3 原生/看一眼.py
QT_QPA_PLATFORM=offscreen python3 原生/量快版.py

# 3) 端到端：让官方 v0.1.7 内核把我们拉起来
export CORTICO_DESKTOP_PET_HOST='["<python>","<本仓库>/原生/原生身体.py"]'
cd <官方 app>/resources/app && node --import tsx core/boot.ts
```

> 素材版本对照的小技巧：`COOP_ASSETS` 指到哪一版，她就是你那一版的样子 ——
> 本文件的两组数字就是只换这个变量量出来的。
